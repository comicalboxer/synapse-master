# Synapse

Official website for Synapse, a student AI club focused on learning, building, and exploring artificial intelligence.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts: Inter and Space Grotesk
- Local PNG logo asset
- Unsplash images for the gallery

This is a static website. It does not require a framework, package manager, build tool, backend, or database.

## Features

- Responsive navigation with a mobile menu
- Hero section with club highlights
- Team member directory
- Featured project showcase
- Events timeline
- Animated image gallery marquee
- Dynamic copyright year
- Pointer-based background and cursor effects

## Run Locally

No dependencies are required. Open `index.html` directly in a browser, or serve the folder with any local static file server.

For example, with Python installed:

```bash
python -m http.server 8000
```

Then visit <http://localhost:8000>.
